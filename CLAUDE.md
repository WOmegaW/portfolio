# CLAUDE.md — портфолио сайтов

- Владелец пишет по-русски, не программист, работает с iPhone. Давать пошаговые инструкции «куда нажать».
- Сайт: https://womegaw.github.io/portfolio/ — GitHub Pages собирает из ветки `claude/tender-ride-vnn4p0`. Держать её и `main` одинаковыми: `git push origin HEAD:main HEAD:claude/tender-ride-vnn4p0` (владелец разрешил пушить в `main`).
- Репозиторий публичный: здесь только демо-сайты с вымышленными компаниями. Никаких секретов.
- Каждый сайт — своя папка (`villas/`, …), без сборщиков: `index.html` (разметка и стили), `app.js` (логика и тексты интерфейса), `data.js` (контент, который меняет покупатель сайта), `img/`. Корневой `index.html` — список работ: добавлять туда каждый новый проект.
- Фото: Unsplash, скачивать и пережимать в WebP (800 и 1600 px), не ссылаться на чужие серверы.
- Шрифты обязательно с кириллицей (Bodoni Moda её не имеет — уже наступали). Сейчас: Prata + Onest.
- Проверять в браузере (Playwright, Chromium предустановлен): десктоп 1440×900 и iPhone 13, нет горизонтальной прокрутки, нет ошибок в консоли.
- В `.claude/` — набор everything-claude-code (ECC), установлен по просьбе владельца. Этот файл важнее правил ECC.
- В футере каждого сайта — пометка, что это концепт и компания вымышлена.
- Перед публикацией гонять проверку функций (Playwright): каталог, фильтры, избранное, сравнение, ссылка `#villa/<id>`, «назад», галерея, калькулятор, языки, телефон.
- GitHub Pages кэширует файлы ~10 минут: при каждом изменении `app.js`/`data.js` менять номер версии в `<script src="app.js?v=…">` и `data.js?v=…` в `villas/index.html` (иначе у владельца новая страница со старым кодом — карта была пустой).
