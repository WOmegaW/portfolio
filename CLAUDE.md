# CLAUDE.md — портфолио сайтов

- Владелец пишет по-русски, не программист, работает с iPhone. Давать пошаговые инструкции «куда нажать».
- Сайт: https://womegaw.github.io/portfolio/ — GitHub Pages собирает из ветки `claude/tender-ride-vnn4p0`. Держать её и `main` одинаковыми: `git push origin HEAD:main HEAD:claude/tender-ride-vnn4p0` (владелец разрешил пушить в `main`).
- Репозиторий публичный: здесь только демо-сайты с вымышленными компаниями. Никаких секретов.
- Каждый сайт — своя папка (`villas/`, …), без сборщиков: `index.html` (разметка и стили), `app.js` (логика и тексты интерфейса), `data.js` (контент, который меняет покупатель сайта), `img/`. Корневой `index.html` — список работ: добавлять туда каждый новый проект.
- Фото: Unsplash, скачивать и пережимать в WebP (800 и 1600 px), не ссылаться на чужие серверы.
- Шрифты обязательно с кириллицей (Bodoni Moda её не имеет — уже наступали). Сейчас: Prata + Onest.
- Проверять в браузере (Playwright, Chromium предустановлен): десктоп 1440×900 и iPhone 13, нет горизонтальной прокрутки, нет ошибок в консоли.
- В `.claude/` — набор everything-claude-code (ECC), установлен по просьбе владельца. Этот файл важнее правил ECC.
- В футере каждого сайта — пометка, что это концепт и компания вымышлена.
- Перед публикацией гонять проверку функций (Playwright): каталог, фильтры, избранное, сравнение, ссылка `#villa/<id>`, «назад», галерея, калькулятор, языки, телефон.
- GitHub Pages кэширует файлы ~10 минут: при каждом изменении `app.js`/`data.js` менять номер версии в `<script src="app.js?v=…">` и `data.js?v=…` в `villas/index.html` (иначе у владельца новая страница со старым кодом — карта была пустой).
- Код с символами `$$` (функция выбора элементов в app.js) править только инструментом Edit: в heredoc командной строки такие строки блокирует проверка безопасности.
- После изменения вилл в `villas/data.js`: из папки `villas` запустить `python3 tools/make-og.py` и `node tools/build-pages.js` (страницы вилл es/en/ru, sitemap, robots, шаблон таблицы) — и закоммитить результат.
- `oferta.html` — коммерческое предложение для агентств (ES/EN); цены пакетов — предложение Claude, владелец может поменять. Контакты владельца — в `CONTACT` внизу файла (пока пустые).
- Фон под разделами виллы — три полосы «о фирме» (`SITE.wall` в `villas/data.js`, фото в `villas/img/brand/`, StockSnap CC0). Первый экран — фото виллы.
- Формы: отдельные поля «Телефон» и «E-mail» (оба обязательны), подсказки-плейсхолдеры через `data-i-ph`.
- Карта районов — настоящая: MapLibre GL 4.7.1 (`villas/vendor/`, лицензия BSD) + бесплатные карты OpenFreeMap (`tiles.openfreemap.org`, без ключа, коммерческое использование разрешено). Если WebGL/карты недоступны — остаётся старая нарисованная SVG-карта. В тестах Playwright запускать Chromium с `--use-gl=swiftshader --enable-webgl --ignore-gpu-blocklist`.
- `nails/` — маникюрный салон Nácar (Марбелья), стиль «кино» в цветах «мягкий шоколад и кофе с молоком» (владелец): фон цвета кофе с молоком `--bg:#D3B99F` (не белый и не бежевый), текст тёмного шоколада, шоколадные блоки — класс `.dk` (первый экран, шапка до прокрутки, интерлюдия, гигиена, подвал) переопределяет цвета на белый текст; зерно плёнки, главы, «билет» записи, финал «Fin.». 3D убрано совсем (владелец: «детско»). Первый экран — слайд-шоу `SLIDES` (фото `img/hero/<img>.webp` 2400 px + `-s` 1200 px, медленный наезд, полоски прогресса; слайд `type:'cert'` — сертификаты мастеров `CERTS`, школы вымышленные). Галерея работ `WORKS` (фото `img/works/<id>.webp` 800 + `-l` 1600, цена, время, техника) → окно работы (анимация «полёт фото из карточки в окно» и обратно, FLIP на Web Animations API: `openWork`/`closeWork` в app.js) → «Записаться» → календарь. На широком экране галерея в 4 колонки. Свой дизайн — WhatsApp с готовым текстом; «Пусть решит мастер» (`ADVICE`, цена «от»); снятие покрытия. Фото — Unsplash (images.unsplash.com по ID; страницы/поиск Unsplash отсюда закрыты, Pinterest нельзя — авторские права). Календарь: показываются все времена дня, занятые — зачёркнуты; уже записанные клиенты занимают время у мастера (в демо — только в этом браузере, localStorage; общему календарю нужен сервер/Google Calendar). «Мои записи» и правило опозданий (>15 мин — отмена и возврат предоплаты). Карта — `../villas/vendor/maplibre-gl.js`. Версию `?v=` менять у data.js и app.js.
