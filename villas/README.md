# Vertiente — сайт агентства вилл (шаблон)

Готовый сайт агентства недвижимости: каталог вилл, фильтры, избранное, сравнение,
калькулятор покупки в Испании, ссылки на каждую виллу, WhatsApp, три языка (ES/EN/RU).
Без сборщиков и сервера: достаточно любого статического хостинга.

## Как поменять под своё агентство
1. **Контакты и название** — `data.js`, блок `SITE` (телефон, WhatsApp, e-mail, адрес).
2. **Виллы** — `data.js`, список `VILLAS`. Чтобы добавить виллу, скопируйте блок `{ id: ... }`
   и поменяйте цифры, тексты и фото. Фото — в `img/` в двух размерах: `имя-800.webp` и `имя-1600.webp`.
3. **Районы на карте** — `data.js`, `AREAS`.
4. **Форма заявки** — сейчас демонстрационная (`SITE.demo = true`). Для настоящих заявок подключается
   любой сервис форм (Formspree, Getform) или CRM агентства.

## Функции
- Живой фон: фото разделов, свет меняется от утра до вечера по мере прокрутки.
- Каталог: районы, спальни, цена, вид на море, новостройка, близость к пляжу, сортировка.
- Избранное (сохраняется в браузере посетителя) и сравнение до трёх вилл.
- Карточка виллы: галерея с листанием пальцем, фото на весь экран, характеристики,
  энергосертификат, кнопки «Поделиться», WhatsApp, запись на просмотр.
- Калькулятор: ITP 7% или IVA 10% + AJD 1,2% для новостроек, нотариус, юрист, ипотека.
- Ссылка на виллу вида `…/villas/#villa/blanca` открывает её сразу; кнопка «назад» закрывает.
