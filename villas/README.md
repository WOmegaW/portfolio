# Vertiente — сайт агентства вилл (шаблон)

Готовый сайт агентства недвижимости: каталог вилл, интерактивная карта побережья, фильтры, избранное,
сравнение, калькулятор покупки в Испании, отдельная страница каждой виллы для Google, заявки на почту,
WhatsApp, юридические страницы, три языка (ES/EN/RU). Без сервера и сборщиков: подходит любой
статический хостинг (Netlify, Cloudflare Pages, GitHub Pages — бесплатно).

## Запуск для нового агентства — по шагам
1. **Контакты и название** — `data.js`, блок `SITE`: `brand`, `phone`, `whatsapp`, `email`, `address`, `url` (адрес сайта).
2. **Заявки на почту** — зайти на https://web3forms.com, ввести e-mail агентства, ключ из письма вписать в `SITE.web3formsKey`.
   Пока ключ пустой, форма демонстрационная.
3. **Юридические данные** — `SITE.legal`: компания, NIF, регистрационные данные, номер RAIA, e-mail по защите данных.
   Страницы `aviso-legal.html`, `privacidad.html`, `cookies.html` подставят их сами. Тексты — шаблон: дать проверить юристу.
4. **Районы** — `AREAS` в `data.js`: название и описание на трёх языках, минуты из аэропорта.
5. **Виллы** — один из двух способов:
   - в `data.js`, список `VILLAS` (фото кладутся в `img/` как `имя-800.webp` и `имя-1600.webp`);
   - в Google Таблице: импортировать `plantilla-villas.csv`, Файл → Поделиться → Опубликовать в интернете → CSV,
     ссылку вписать в `SITE.sheetUrl`. В колонке `photos` можно указывать прямые ссылки на фото через `|`.
6. **Страницы вилл для Google** (из папки `villas`):
   ```
   python3 tools/make-og.py      # превью для ссылок в WhatsApp/соцсетях (нужен Pillow)
   node tools/build-pages.js     # страницы es/en/ru/<вилла>/, sitemap.xml, robots.txt, шаблон таблицы
   ```
   Запускать после изменения вилл в `data.js`. Если виллы ведутся в Google Таблице, страницы для Google
   строятся из `data.js` — их обновляют при обслуживании сайта.
7. **Статистика (необязательно)** — `SITE.plausible` (без cookies) или `SITE.gaId` (Google Analytics,
   включается только после согласия посетителя в баннере).
8. Опубликовать папку на хостинге, подключить домен, отправить `sitemap.xml` в Google Search Console.

## Что есть на сайте
- Живой фон: фото разделов, свет меняется от утра до вечера по мере прокрутки; часы в углу.
- Каталог: районы, спальни, цена, вид на море, новостройка, близость к пляжу, сортировка; карточки «влетают».
- Избранное и сравнение до трёх вилл; ссылка `…/#villa/<id>` открывает виллу, «назад» закрывает.
- Окно виллы: галерея с листанием пальцем, фото на весь экран, калькулятор ITP 7% / IVA 10% + AJD 1,2%, нотариус, юрист, ипотека.
- Карта побережья: районы с полётом камеры, ценники вилл, карточка виллы с калькулятором прямо в панели.
- Страница каждой виллы на трёх языках: данные schema.org (RealEstateListing), hreflang, превью ссылок.
- Заявки (Web3Forms) с защитой от спама, WhatsApp с готовым текстом.
- Юридические страницы и номер RAIA в подвале; баннер cookies, если включён Google Analytics.

## Видео-тур и 3D-тур 360°
- **Видео-тур** есть у каждой виллы: сайт сам собирает «фильм» из её фото (плавный наезд камеры, подписи комнат, титры, в конце — кнопки записи). Если у агентства есть настоящее видео — впишите в виллу `video: 'https://youtu.be/…'` (или ссылку на .mp4).
- **3D-тур 360°**: у виллы `tour: 'demo'` (демо-набор панорам из `TOURS` в data.js), свой список `[{ pano: 'имя', name: { ru, es, en } }]` или ссылка Matterport.
  Панорама — фото 360° 2:1 в `img/pano/`: `имя.webp` (4096×2048), `имя-s.webp` (2048×1024), `имя-t.webp` (маленькая).
- Прямые ссылки для клиентов: `…/villas/#video/<id>` и `…/villas/#tour/<id>`.
- Демо-панорамы — Poly Haven (polyhaven.com), лицензия CC0.
